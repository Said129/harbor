# Limitaciones verificadas de iOS

Las tareas pendientes de implementación y las capacidades aún no probadas se registran en FEATURE_PARITY y VALIDATION, no como limitaciones del sistema operativo.

| Restricción comprobada                                                            | Evidencia primaria                                                                                                                      | Efecto concreto                                                                           | Alternativa                                                                                                             |
| --------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------- |
| Compilar/enlazar los targets iOS requiere el iOS SDK de Xcode                     | [Rust: Apple iOS targets](https://doc.rust-lang.org/rustc/platform-support/apple-ios.html)                                              | Este Windows no valida enlace Apple/SwiftUI                                               | GitHub Actions macOS con Xcode y builds device/simulator                                                                |
| iOS limita el tiempo de ejecución general en background y puede suspender una app | [Apple: Extending background execution](https://developer.apple.com/documentation/uikit/extending-your-app-s-background-execution-time) | No garantizar DHT/peers/DVR/relay local funcionando indefinidamente con la app suspendida | Lifecycle explícito, audio legítimo cuando proceda, transferencias URLSession background y servidor remoto configurable |
| ATS aplica requisitos de seguridad a conexiones del sistema                       | [Apple: ATS keys](https://developer.apple.com/documentation/bundleresources/information-property-list/nsapptransportsecurity)           | URLSession puede rechazar addons HTTP o TLS inválido                                      | HTTPS con certificados válidos; excepciones justificadas específicas/locales, nunca desactivar certificate validation   |
| Una app device unsigned no satisface los requisitos de instalación normal         | [Apple: Code signing](https://developer.apple.com/support/code-signing/)                                                                | El artefacto .app de CI prueba compilación, no instalación física                         | Configurar certificados y provisioning separadamente antes de exportar build instalable                                 |

No hay evidencia aquí de una prohibición técnica absoluta de torrents, MKV, ASS, FFmpeg o libmpv integrado. Tampoco hay garantía de HDR/Dolby Vision, AirPlay/PiP con libmpv o AV1 en todo iPhone. Estos puntos requieren experimentos y pruebas por dispositivo.
