# Original Music genres and scenes on iOS

The new Explore page adds the original 0.9.132 genre browser, country and style
filters, aliases, localized scene names, persistent filter settings, and actual
genre pages. The pinned catalog contains 159 identities; the native browser shows
158, omitting the children's genre under the owner's exclusion of a Kids section.
Its eight style families, country tags, remote cover references and 158 original
vector drawings are retained. The vector import only supplies the original wrapper
and theme ink; it keeps the drawing geometry.

Six original TypeScript modules run in the existing isolated trusted WebKit worker.
The host allows anonymous public GET requests to the original Deezer API. No account
credentials are passed to that worker. The original request coalescing and
fifteen-minute cache, exact editorial recording membership, bounded scene searches,
playlist pool and depth paging remain in the original source. The genre grid makes
no provider requests while filtering. Cover requests are lazy and use the shared
bounded artwork loader. The worker starts when Explore is opened.

The native page keeps selected countries and style across navigation and relaunch,
with individual country removal and reset. Its search binding is independent of
For you and Library. Genre pages expose chart positions, track metadata, album,
artist and playlist references, related scenes and further original depth pages.
The anonymous catalog remains browse-only. This is part of full Explore parity:
the remaining video/festival, Billboard, recommendation and artist-roster features,
taste onboarding and connected playback still require their full original adapters.
